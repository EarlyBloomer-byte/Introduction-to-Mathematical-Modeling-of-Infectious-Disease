# Workflow note (updated)

Earlier revisions of this repo paused after each subsection for a go-ahead. Per the repo owner's
instruction, that pause is removed: sections are now produced back-to-back, chapter by chapter,
without stopping to ask. `python/` and `r/` are organized as top-level folders with one
subfolder per chapter (`python/chapter_01/`, `r/chapter_01/`, etc.), mirroring each other.

Realistic scope note (still true): the full 14-part treatment (rewrite, ELI10, full derivation,
symbol glossary, intuition, visualization, tested Python, tested R, numerical verification, 12
practice problems + solutions, summary, memory aids, connections) applied to every paragraph of a
161-page, 5-chapter book is a large body of work. It is being built continuously, in chapter
order, across as many sections as fit per working session — see `PROGRESS.md` for exactly how far
it has gotten.
